### ✅ 1. 文件去重

**实现位置**：`python-agent-service/app/middleware/intent_understanding.py`

**实现内容**：
- 在文件解析后、意图理解前进行文件去重
- 基于 `hash_sha256` 检测重复文件
- 只保留第一个文件，跳过后续重复文件
- 记录重复文件映射到 `IntentResult.metadata.duplicate_files`
- 记录统计信息（总文件数、唯一文件数、重复文件数）

**代码变更**：
```python
# 在文件解析后添加去重逻辑
seen_hashes: dict[str, FileInfo] = {}
unique_files: list[FileInfo] = []
duplicate_map: dict[str, str] = {}

for file_info in parsed_files:
    file_hash = file_info.hash_sha256
    if file_hash and file_hash in seen_hashes:
        # 发现重复文件，记录并跳过
        duplicate_map[file_info.filename] = seen_hashes[file_hash].filename
    else:
        if file_hash:
            seen_hashes[file_hash] = file_info
        unique_files.append(file_info)

# 存储去重信息到结果元数据
if duplicate_map:
    result.metadata["duplicate_files"] = duplicate_map
    result.metadata["total_files"] = len(parsed_files) + len(duplicate_map)
    result.metadata["unique_files"] = len(parsed_files)
```

- **生成合并任务**：当需要综合报告时，创建额外的合并任务
- **合并任务示例**：提供了详细的 JSON 示例
